How to use

  • Add a state: double-click on the canvas
  • Add an arrow: shift-drag on the canvas
  • Move something: drag it around
  • Select several states: right-drag a box around them (hold shift to add to the selection)
  • Move a selection: drag any highlighted state and they all move together
  • Copy / cut / paste: Ctrl+C / X / V — transitions come along when both of their states do
  • States or label text? whichever you copied last is what Ctrl+V pastes
  • Delete something: click it and press the delete key
  • Make accept state: double-click on an existing state
  • Rename: click a state or arrow and start typing
  • Edit mid-label: click into the label to put the cursor there; ← → Home End move it
  • Highlight label text: drag across an arrow's label, or hold Shift with the arrow keys, or Ctrl+A
  • Copy label text: highlight it and press Ctrl+C — it goes to the system clipboard
  • Subscript: put an underscore before it — digits or letters (like S_0 or q_a), and braces for more than one character (like q_{start})
  • Greek letter: put a backslash before it (like \beta)
  • Pan: drag an empty part of the canvas (or alt-drag / middle-drag anywhere)
  • Zoom: scroll wheel, the + / − buttons, or Ctrl++ / Ctrl+−

The canvas is unbounded — pan and zoom to build diagrams of any size. States automatically stretch into a pill shape so long names fit inside them.

The “Connect to Claude” button

This page can hand the machine you have drawn to Claude Code running on your own computer, so you can ask it things about your actual diagram instead of describing one. It can then read the machine, tell you what is wrong with it, run strings through it, convert it — determinise, minimise, complement, reverse — and animate the working step by step. Anything it changes appears on your canvas about a second later, still yours to edit.

To connect: install the fsm-designer MCP server, ask Claude to open the designer, then press Connect to Claude in the toolbar above. Whatever is already on your canvas is carried over — you do not lose your work by connecting. Your browser remembers the choice, so later visits reconnect on their own.

Nothing is sent anywhere except to that program on your own machine, over a plain localhost connection. This site has no server of its own and no account to sign in to; your diagrams have always lived in this browser and still do. Until you press the button the page makes no such connection at all, and if you never press it, it never looks. A one-time key means only the session you connected to can read or change the canvas, and it stops working when that session ends.

An independent rebuild of the Finite State Machine Designer created by Evan Wallace in 2010, which this owes its concept and interaction design to.

This version adds states that stretch into a pill shape to fit long names, a Clear All button, and a pannable, zoomable canvas. Source on GitHub.
